# Know Your Police Rights — Citizen's Guide for India

A web app that helps Indian citizens understand what to do in different situations involving the police — built for the **Independence Day Lets Code Development Challenge**.

## The Core Idea

**Situation → Your Rights → What To Do → Where To Complain**

Simple enough that a person in a stressful situation can understand what to do within 30 seconds.

## Situations Covered

- Stopped or questioned by police
- Arrested or detained
- Police refuse to register an FIR
- Search & seizure of you or your property
- Threatened, abused, or assaulted by an officer
- Asked for a bribe
- Where to complain (directory of authorities)

## Features

- **Situation cards** — tap any situation to see your rights, exact steps to take, and where to complain
- **AI-style chatbot assistant** — type your situation in plain language and get instant guidance with follow-up suggestions
- **Emergency helpline directory** — 112, 1091 (women), 1098 (child), 1930 (cyber crime), 15100 (legal aid), and more, all tap-to-call
- **Golden rules** — quick tips that protect you in almost every situation
- **Mobile-first responsive design** with Indian tricolor accents
- Built with React, TypeScript, Vite, and Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build outputs to the `dist/` folder.

## Deploy / Host

This is a static site — the `dist/` folder can be hosted on:

- **Netlify** — drag-and-drop the `dist` folder, or connect your GitHub repo
- **Vercel** — import the repo, framework preset: Vite
- **GitHub Pages** — push the `dist` output to a `gh-pages` branch

## Tech Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- lucide-react icons
- Pexels stock imagery (HD)

## Disclaimer

This app provides general legal awareness and guidance — it is **not a substitute for professional legal advice**. For emergencies, always dial **112**.
